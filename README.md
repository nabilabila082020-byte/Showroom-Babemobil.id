# babemobil.id - Mini Website Showroom Mobil

Website profil showroom mobil modern dan responsif untuk **babemobil.id**, dilengkapi dengan fitur katalog unit interaktif, filter kategori (MPV, SUV, LCGC, Pickup), formulir pemesanan & nego langsung ke WhatsApp, informasi kontak, Google Maps, dan testimoni pelanggan.

## ✨ Fitur Utama
- **Mobile-First & Responsif**: Tampilan modern yang nyaman dibuka di perangkat mobile maupun desktop.
- **Katalog Unit Interaktif**: Tampilan horizontal scroll dengan filter kategori (Semua, MPV, SUV, LCGC, Pickup).
- **Integrasi WhatsApp Otomatis**: Form pesan unit, nego harga, dan test drive terhubung langsung ke nomor WhatsApp dengan template pesan otomatis.
- **Sticky WhatsApp Button**: Tombol CTA WhatsApp mengambang saat halaman digeser.
- **Modal Bagikan (Share)**: Fitur salin tautan dan bagikan ke media sosial (WhatsApp, X/Twitter, Facebook).
- **FAQ & Testimoni**: Informasi tanya jawab dan ulasan pelanggan.

## 🛠️ Teknologi yang Digunakan
- **React 18**
- **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**

## 🚀 Cara Menjalankan Proyek

### 1. Clone Repository
```bash
git clone https://github.com/nabilabila082020-byte/Showroom-Babemobil.id.git
cd Showroom-Babemobil.id
```

### 2. Instal Dependensi
```bash
npm install
```

### 3. Jalankan Development Server
```bash
npm run dev
```
Buka browser di `http://localhost:3000`.

### 4. Build untuk Produksi
```bash
npm run build
```
